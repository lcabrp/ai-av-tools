## Detalles del Estado Actual

### 1. Análisis del Input Recibido

- **Estado detectado:** Vacío / Sin texto.
- **Implicación:** No hay datos para procesar, deduplicar o resumir en este momento.

### 2. Instrucciones de Formato Listas para Aplicarse
Una vez proporcionado el contenido, se aplicarán las siguientes reglas estrictas:
- **Idioma:** Todo el resumen será generado en español.
- **Estructura:**
  - Título principal.
  - Tabla de contenidos / Lista de temas clave.
  - Secciones por tema con viñetas anidadas (no listas planas).
  - Sección final de 'Acciones' o 'Próximos Pasos'.
- **Integridad de Datos:**
  - No se perderán detalles específicos (precios, porcentajes, fechas, duraciones, cantidades).
  - Se preservarán nombres propios (personas, herramientas, empresas, URLs, correos).
  - Se mantendrá el orden paso a paso de las instrucciones o procesos.
  - Se conservarán declaraciones de causa-efecto o condicionales ("si X pasa, haz Y").
  - Se incluirán elementos concretos: ítems de acción, decisiones, plazos, siguientes pasos.
- **Epistemología:**
  - Las preguntas permanecerán como preguntas.
  - Los ejemplos permanecerán como ejemplos.
  - Las ideas rechazadas se mantendrán como rechazadas.
  - Solo las respuestas o decisiones explícitas se convertirán en recomendaciones.
  - Se preservará la atribución de hablantes/propietarios.
  - Se conservarán nombres inciertos, correcciones y contradicciones sin resolverlas.

### 3. Solicitud al Usuario
- **Acción requerida:** Por favor, proporcione el texto completo de las notas o fragmentos de transcripción que faltan.
- **Formato de entrada esperado:** Puede ser un bloque de texto, una lista de puntos, o cualquier formato de transcripción.
- **Objetivo:** Generar el resumen detallado y listo para usar según las especificaciones anteriores.
